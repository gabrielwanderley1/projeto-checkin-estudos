## 🛠 Arquitetura e Tecnologias

Projeto desenvolvido com foco em fundamentos robustos de engenharia de software no Front-end, estruturando regras de negócio, responsividade e estado da aplicação como base para a futura integração com um banco de dados relacional (SQL).

* **Tech Stack:** HTML5, CSS3 (Custom Properties para Theming Light/Dark) e JavaScript Puro (Vanilla ES6+).
* **Gerenciamento de Dados:** Persistência local utilizando `localStorage` e manipulação estruturada via JSON, atuando como um *mock database* para validação da lógica.
* **Padrões de UI/UX:** Transições em formato Single Page Application (SPA) via manipulação do DOM (sem recarregamento de página), Grid/Flexbox adaptativo e prevenção de *Flash of Unstyled Content* (FOUC).
* **Metodologia (AI-Assisted Development):** Divisão estratégica de papéis no desenvolvimento. O **Gemini** foi utilizado para o planejamento da arquitetura e engenharia de prompts, atuando como Tech Lead, enquanto o **GitHub Copilot** foi responsável pela execução e geração de códigos. Essa abordagem garantiu o controle estrutural e evitou dependências de frameworks externos.
